# SavorCline — website and live demo

Static site with no runtime dependencies. Requires Node 18+ for the page generator, local server and tests.

```
npm run build  # regenerate the static HTML pages from src/data/business.js
npm run dev    # http://localhost:5173
npm test       # risk engine + business-record tests
```

## Pages

Every page except the demo and 404 is generated by `scripts/build-pages.mjs` as plain static HTML (crawlable without JavaScript). Edit the generator or `src/data/business.js`, run `npm run build`, and commit the generated `.html`, `sitemap.xml` and `robots.txt`.

| Page | Purpose |
|---|---|
| `index.html` | Home: hero, problem with sourced industry figures, features, how it works, solutions, comparison, AI, safeguards, AWS, roadmap, pricing, team, FAQ |
| `product.html`, `how-it-works.html`, `solutions.html`, `technology.html`, `security.html`, `pricing.html`, `about.html`, `contact.html` | Marketing pages |
| `privacy.html`, `terms.html` | Legal pages (flag for legal review: governing law and legal entity are not set) |
| `demo.html` | Live demo: products & allergens, schedule, sequencing, cleaning records, document extraction, report. Runs in the browser on sample data; no accounts |
| `404.html` | Not found |

Vercel serves clean URLs (`/product` → `product.html`) and redirects the old `/app` and `/center` paths (see `vercel.json`).

## Single source of truth

`src/data/business.js` holds every business fact. `null` means not supplied, and public pages hide anything null.

Business email: `bello@savorcline.site`. The early-access form opens a pre-filled email to it; set `formEndpoint` to POST to a form service instead. Optional facts not yet set: `headquarters`, `linkedinUrl`, founder `linkedin`.

Pricing on the site is **proposed** launch pricing ($249 / $599 per site per month, Group custom), labelled as such. Confirm or change it in `scripts/build-pages.mjs`.

## Deploying

Live at https://www.savorcline.site (Vercel).

**Vercel:** import the repo with framework preset "Other", no build command, root directory `./`. `vercel.json` already sets this, and `.vercelignore` keeps `package.json` out of the upload. The local preview server lives in `scripts/` so Vercel serves the folder as static files instead of trying to run a Node server. If a deploy shows unstyled black-on-white text, the CSS and JS files are not being served: check that the project's Root Directory is the repo root.

All links are relative and extensionless (`product`, `demo`), so any other static host (S3 + CloudFront, Amplify Hosting, Netlify) needs clean-URL rewrites from `/page` to `/page.html`.
