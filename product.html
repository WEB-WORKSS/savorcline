Five checks between the supplier spec and the first run.

Each capability works on the same allergen profiles and schedule, so a change in one place is re-checked everywhere it matters. All five can be tried in the live demo today.

Allergen risk detection

Checks every changeover on every line: which allergens the previous run leaves behind that the next product does not declare.

Unsafe sequences are visible before the shift, not after a swab fails.

Rule-based engine in this repository. AI-assisted risk explanation via Amazon Bedrock is planned.

Safer production sequencing

Suggests a run order per line that needs the fewest allergen cleans, for the planner and QA team to review and approve.

Fewer full wet cleans, fewer risky changeovers, same products.

Exhaustive search for up to 8 runs per line, greedy ordering above that.

Cleaning verification

Matches cleaning records to the changeovers that need them and flags missing sign-offs, wrong clean types and absent swab results.

Documentation gaps surface on the day, not at audit.

Document intelligence

Reads ingredient lists and supplier specifications and maps ingredients such as whey, casein or spelt to the allergen they contain.

Allergen profiles built from source documents instead of retyped by hand.

Demo uses keyword and synonym matching on pasted text. Amazon Textract + Amazon Bedrock extraction is planned.

Compliance reporting

Produces a dated allergen-risk report for a schedule: findings, required cleans, cleaning gaps and a sign-off block.

Traceable evidence for internal review and audits.
